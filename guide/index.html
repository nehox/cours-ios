Étape 0 cours/CoursProductivite/App/CourseBootstrap.swift

Le Baptême du Compilateur Swift

À l'ouverture du projet dans Xcode, tentez une première compilation avec Cmd + B. Le compilateur refuse catégoriquement d'aller plus loin : une erreur de typage statique a été délibérément insérée au démarrage.

❌ Error: cannot convert value of type 'String' to specified type 'Int'
Observez la ligne 7 de CourseBootstrap.swift : la constante message reçoit une chaîne de caractères entre guillemets mais a été annotée : Int. En Swift, le typage est strict : changez l'annotation de type pour que le compilateur soit satisfait !
CourseBootstrap.swift 
enum CourseBootstrap {
    // Correction : annoter avec String (ou laisser l'inférence faire son travail !)
    static let message: String = "Corrige la base, puis fais évoluer l’écran avec le TDD."
    ...
}

Lesson 01 : Structures & Immuabilité

Lancez maintenant la suite de tests avec Cmd + U. Le premier test unitaire à faire passer est testLesson01SummaryFormatsTitleAndObjective dans LessonTests.swift.

LessonTests.swift (L'attente métier) 
func testLesson01SummaryFormatsTitleAndObjective() {

Utilisez l'interpolation de chaînes en Swift : "\(variableA) - \(variableB)". En Swift moderne, si une fonction n'est composée que d'une seule expression, le mot-clé return est optionnel !

struct Lesson01Basics {
    let title: String
    let objective: String

    init(title: String, objective: String) {
        self.title = title
        self.objective = objective
    }

    func summary() -> String {
        "\(title) - \(objective)"
    }
}

Étape 2 cours/CoursProductivite/Lessons/Lesson02_Optionals.swift

Lesson 02 : Sécuriser les Optionnels sans Crash

Les optionnels (T?) représentent l'absence potentielle de valeur. Implémentez la fonction de nettoyage trimmedTitle(from title: String?) afin de satisfaire les tests testLesson02TrimsOptionalTitle et testLesson02ReturnsNilForEmptyValue.

1. Utilisez la sortie précoce : guard let title else { return nil }.
2. Nettoyez les espaces : let candidate = title.trimmingCharacters(in: .whitespacesAndNewlines).
3. Si candidate.isEmpty vaut true, retournez nil, sinon retournez candidate.
Lesson02_Optionals.swift 
enum Lesson02Optionals {
    static func trimmedTitle(from title: String?) -> String? {
        guard let title else {
            return nil
        }

        let candidate = title.trimmingCharacters(in: .whitespacesAndNewlines)
        return candidate.isEmpty ? nil : candidate
    }
}

Étape 3 cours/CoursProductivite/Domain/*

Le Cœur Métier : Task, TaskPolicy & TaskList

Les modèles de données en Swift sont construits avec des struct (Value Types). Pour modifier une propriété interne d'une structure, la méthode doit être annotée mutating.

Task.swift
Priorité par défaut : .medium, et méthode markDone() qui passe isDone = true.
TaskPolicy.swift
Valide que le titre nettoyé de ses espaces n'est pas vide (canCreateTask).
TaskList.swift
Implémenter add(_:), completeTask(withID:) et le filtre calculé pendingTasks.
Domain/Task.swift 
init(id: UUID = UUID(), title: String, isDone: Bool = false, priority: Priority = .medium) {
    self.id = id
    self.title = title
    self.isDone = isDone
    self.priority = priority
}

mutating func markDone() {
    isDone = true
}
Domain/TaskPolicy.swift 
struct DefaultTaskPolicy: TaskPolicy {
    func canCreateTask(title: String) -> Bool {
        title.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty == false
    }
}
Domain/TaskList.swift 
var pendingTasks: [ProductivityTask] {
    tasks.filter { $0.isDone == false }
}

mutating func add(_ task: ProductivityTask) {
    tasks.append(task)
}

mutating func completeTask(withID id: UUID) {
    guard let index = tasks.firstIndex(where: { $0.id == id }) else {
        return
    }
    tasks[index].markDone()
}

Étape 4 cours/CoursProductivite/Lessons/Lesson04_ViewModel.swift

Lesson 04 : Protocoles & ViewModel Isolé

Grâce au protocole Lesson03TaskProviding, le ViewModel ne connaît pas la vraie base de données : il reçoit son fournisseur de données par injection dans son init(provider:).

🎯 Règle de présentation : La propriété calculée taskCountText doit renvoyer "Aucune tâche" lorsque le tableau est vide, ou "\(count) tâche(s)" s'il y a des tâches.
Lesson04_ViewModel.swift 
@MainActor
final class Lesson04ViewModel {
    private let provider: Lesson03TaskProviding

    init(provider: Lesson03TaskProviding) {
        self.provider = provider
    }

    var taskCountText: String {
        let count = provider.currentTasks().count
        return count == 0 ? "Aucune tâche" : "\(count) tâche(s)"
    }
}

Étape 5 cours/CoursProductivite/Lessons/Lesson05_HomeScreenViewModel.swift

Lesson 05 : Le Cerveau de l'Écran d'Accueil

Ce ViewModel est conforme à ObservableObject et annoté @MainActor. Il expose une liste observable @Published private(set) var tasks et des propriétés calculées pour afficher la progression.

completedCount Nombre de tâches avec isDone == true
pendingCount tasks.count - completedCount
pendingCountText "Tout est fini" si 0, sinon "\(pendingCount) en cours"
markTaskDone(withID:) Trouve la tâche ciblée et appelle sa méthode markDone()
Lesson05_HomeScreenViewModel.swift 
var completedCount: Int {
    tasks.filter { $0.isDone }.count
}

var pendingCount: Int {
    tasks.count - completedCount
}

var completedCountText: String {
    "\(completedCount) terminée(s)"
}

var pendingCountText: String {
    pendingCount == 0 ? "Tout est fini" : "\(pendingCount) en cours"
}

func markTaskDone(withID id: UUID) {
    guard let index = tasks.firstIndex(where: { $0.id == id }) else {
        return
    }

    tasks[index].markDone()
}
